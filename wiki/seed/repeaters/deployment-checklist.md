# Repeater deployment checklist

Copy this list into your build page and tick it off.

> Outdoor installs can involve heights, batteries and lightning. Never work on a roof or mast alone, and get the site owner's permission in writing.
{.is-danger}

## 1. Plan

- [ ] Agreed the site with the community on the [region page](/cape-town/region) (role, nearby repeaters)
- [ ] Permission from the site owner / body corporate
- [ ] Safe access to the mounting point

## 2. Bench test (at home)

- [ ] Flashed repeater firmware; noted the version
- [ ] Applied the [recommended settings](/settings/recommended)
- [ ] Set node name and a strong admin password
- [ ] Heard by and can relay for at least one companion
- [ ] Ran on battery for 48+ hours to measure real consumption

## 3. Power

- [ ] Battery sized for several cloudy winter days with no sun
- [ ] Solar panel sized for winter sun, not summer
- [ ] Charge controller suits the battery chemistry; low-voltage cut-off set
- [ ] Batteries kept out of direct sun where possible (heat shortens life)

## 4. Enclosure and weather

- [ ] IP-rated enclosure, cable glands sealed, drip loops on cables
- [ ] Vent or breather to stop condensation
- [ ] UV-resistant cable ties and materials

## 5. Antenna and RF

- [ ] Antenna connected **before** power-on
- [ ] Antenna gain + transmit power within ICASA limits (record the numbers)
- [ ] Feedline kept short; connectors weatherproofed
- [ ] Mast earthed / lightning protection where exposed

## 6. After install

- [ ] Confirmed heard from at least two locations
- [ ] Added to the [known repeaters](/cape-town/region) table (area only)
- [ ] Admin password shared privately with one trusted person as backup
- [ ] Calendar reminder to check it quarterly
