# Contributing

This wiki is written by the people building the mesh. You don't need permission to improve a page — create an account, log in, and click **Edit**.

## How to edit

1. **Create an account** (top right). Email and password — nothing else needed.
2. Open any page and click the **pencil / Edit** button.
3. Write in Markdown. The editor shows a live preview.
4. Add a short note describing your change and **Save**.

Every edit is kept in the page **History**, so mistakes are easy to undo.

## Starting a new page

- Use the **New Page** button, pick the section that fits, and give it a short, lower-case path (for example `/hardware/rak-wisblock-repeater`).
- Documenting a build? Copy the template from [Hardware builds](/hardware/builds).

## House rules

- **Be accurate.** Say what you tested and how. One person's result isn't a universal rule — write "worked for me at…" rather than "always use…".
- **Be kind.** Fix errors quietly; discuss disagreements on the page's comments.
- **Cite sources** for settings, regulations and specs where you can.
- **Mark unknowns.** If something needs checking, write `TODO:` so others can help.

## Never publish

> These rules protect members' safety and the network.
{.is-warning}

- **Exact home locations** — of your node or anyone else's. Use a suburb or a rough area.
- **Local IP addresses, passwords, admin keys, tokens** or Home Assistant URLs.
- **Other people's personal details** without their permission.
- **Repeater admin passwords** — share those privately with the site owner only.
