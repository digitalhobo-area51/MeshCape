# Start here

Welcome to the **MeshCape wiki** — the shared notebook for people building an off-grid [MeshCore](https://meshcore.co.uk) LoRa mesh across Cape Town. Anyone with a MeshCape account can edit. If you know something useful, write it down.

> New to MeshCore? Read the three-step guide on [meshcape.io/get-started](https://meshcape.io/get-started/) first, then come back here for the detail.
{.is-info}

## What is MeshCore?

MeshCore is open-source firmware that turns small, low-power LoRa radios into a text-messaging mesh. Messages travel radio to radio — no cell towers, no internet, no subscription. Fixed **repeaters** on high ground relay traffic so it can cross the city.
